# 더존 iCUBE 전표 업로드 변환기 (엑셀 VBA)

통장·카드 거래내역 엑셀을 iCUBE 전표 엑셀 업로드용(차변/대변 대체전표) 양식으로 바꿔 주는 매크로입니다.

| 파일 | 내용 |
|---|---|
| `iCUBE_전표변환.xlsx` | 시트 구성: 사용방법 / 설정 / 계정매핑 / 원본(예시 데이터) / 업로드 |
| `iCUBE전표변환.bas` | VBA 모듈 (매크로: `전표변환`, `업로드파일저장`, `원본비우기`) |

## 설치 (한 번만)
1. `iCUBE_전표변환.xlsx` 열기 → `Alt+F11` → 파일 → 파일 가져오기 → `iCUBE전표변환.bas`
2. **Excel 매크로 사용 통합 문서(.xlsm)** 로 다른 이름 저장
3. [설정]에서 보통예금/미지급금 계정코드·거래처코드, 출력 열 순서(iCUBE 샘플 양식과 동일하게)를 맞춤

## 사용
원본 붙여넣기 → `Alt+F8` `전표변환` → 노란 줄(계정 미지정) 확인 → `업로드파일저장` → iCUBE에서 불러오기

자세한 설명은 엑셀의 [사용방법] 시트를 참고하세요.
