# ETC

## household_ledger.html — 우리집 가계부

카드사 앱 **승인 알림 목록 캡쳐**를 올리면 가맹점 · 금액 · 날짜 · 시간 · 사용자(가족카드) · 카드 · 할부를 자동으로 읽어 가계부에 입력합니다.

- 브라우저에서 파일 하나만 열면 동작 (서버 불필요, 데이터는 기기 브라우저 localStorage에 저장)
- 한글 OCR: [Tesseract.js](https://github.com/naptha/tesseract.js) (이미지가 외부로 전송되지 않고 브라우저 안에서 인식)
- 다크모드 캡쳐 자동 반전 · 확대 전처리, 겹친 캡쳐 중복 저장 방지, 승인취소 인식
- 가맹점 이름으로 분류 자동 지정, 분류를 고치면 같은 가맹점은 다음부터 자동 적용
- 월별 내역 / 분류·사용자·일별·가맹점 통계 / 예산 / 6개월 추이
- JSON 백업·복원, 엑셀용 CSV 내보내기
- **부부 실시간 공유 (무료)**: 설정 탭에서 Google Firebase 무료 요금제(Firestore + 익명 로그인)를 연결하면, 공유 링크를 연 모든 기기에 실시간 반영
  - 필요한 Firestore 보안 규칙은 앱 설정 화면에 들어 있음 (가계부 코드를 모르면 읽기·쓰기 불가, 목록 조회 불가)
  - 페이지는 GitHub Pages 등 무료 정적 호스팅에 올려 사용

## family_calendar.html — 우리 가족 달력

가족이 함께 보는 달력 · 일정 · 할 일 앱입니다.

- 월 달력: 구성원별 색으로 일정 표시, 날짜를 누르면 그날 일정 목록, 좌우로 밀어 달 넘기기
- 일정: 종일 / 시각, 여러 날 일정, 참여자 여러 명(안 고르면 가족 모두), 장소 · 메모
- 반복: 매일 · 매주 · 매월 · 매년 (생일 등), 반복 끝나는 날, 반복 중 하루만 삭제
- 구성원 필터: 보고 싶은 사람 일정만 보기 (기기마다 따로 기억)
- 일정 목록: 앞으로 90일, 제목 · 장소 · 메모 검색
- 할 일: 담당자 · 기한, 기한 지난 항목 빨간색 표시
- 대한민국 공휴일 · 대체공휴일 표시 (2025~2027년)
- **가족 실시간 공유 (무료)**: 가계부와 같은 방식(Google Firebase 무료 요금제)으로 연결, 공유 링크를 연 모든 기기에 실시간 반영
  - 가계부와 같은 Firestore 보안 규칙을 쓰므로, 가계부용 Firebase 프로젝트를 그대로 써도 됨 (같은 브라우저에 가계부 공유가 연결돼 있으면 버튼 하나로 생성)
- 홈 화면에 추가하면 앱처럼 실행 (아이콘 포함)
