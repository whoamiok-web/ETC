가족과 공유 이 기기에만 저장

홈 화면 앱은 브라우저와 저장공간이 따로입니다. 브라우저에서 이미 공유 달력을 쓰고 있다면, 그 화면의 공유 링크 복사로 복사한 링크를 아래 칸에 붙여넣어 연결하세요.
공유 달력에 연결됨 · Firebase 프로젝트
아래 링크를 가족에게 보내면, 링크를 여는 것만으로 같은 달력이 연결됩니다. 링크를 아는 사람은 누구나 볼 수 있으니 가족끼리만 공유하세요.
가족이 보낸 공유 링크가 있나요? 링크를 붙여넣으세요.
가계부에 연결한 Firebase가 있습니다. 같은 프로젝트에 달력을 따로 만들 수 있습니다. (추가 설정 없음)
지금은 이 기기에만 저장됩니다. Google Firebase 무료 요금제를 연결하면 가족 모두가 같은 달력을 실시간으로 봅니다. (한 번만 설정, 약 5분)
설정 방법 보기
  1. Firebase 콘솔에 Google 계정으로 로그인 → 프로젝트 만들기 (이름 예: our-family, 애널리틱스는 꺼도 됨)
  2. 왼쪽 메뉴 빌드 → Authentication → 시작하기 → 로그인 방법에서 익명을 사용 설정 후 저장
  3. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3 (서울) → 프로덕션 모드로 시작
  4. Firestore의 규칙 탭에 아래 규칙을 붙여넣고 게시 (가계부와 같은 규칙이라, 가계부용 프로젝트를 그대로 써도 됩니다)
  5. 프로젝트 개요 옆 ⚙️ 프로젝트 설정 → 아래쪽 내 앱에서 웹(</>) 앱 추가 → 나오는 firebaseConfig 부분을 복사해 아래 칸에 붙여넣기
가족은 설정 없이 공유 링크만 열면 됩니다.

알림

위의 가족과 공유를 연결하면, 가족이 새 일정을 등록할 때 알림을 받을 수 있습니다.
앱이 닫혀 있어도 휴대폰으로 알림 받기
  1. 휴대폰에 무료 앱 ntfy를 설치합니다. (App Store · Play 스토어에서 "ntfy" 검색)
  2. ntfy 앱에서 ＋ (Subscribe to topic)를 누르고, 아래 주제 이름을 붙여넣은 뒤 Subscribe를 누릅니다. 서버는 기본값(ntfy.sh) 그대로 두세요.
  3. 가족 모두 같은 주제를 구독하면 끝입니다.
알림은 무료 공개 서버 ntfy.sh를 거쳐 전달됩니다. 주제 이름을 아는 사람은 알림 내용(일정 제목·날짜)을 볼 수 있으니 가족끼리만 공유하세요. 일정을 등록한 사람의 휴대폰에도 같은 알림이 옵니다.
앱을 열어 둔 동안 알림
가족이 일정을 등록하면 화면 위에 새 일정이 표시됩니다. 다른 앱을 보는 동안에도 알림 창에 띄우려면 허용해 주세요. 아이폰은 홈 화면에 추가한 앱에서만 됩니다.
