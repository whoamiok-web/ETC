가족이 보낸 공유 링크가 있나요? 링크를 붙여넣으세요.
가계부에 연결한 Firebase가 있습니다. 같은 프로젝트에 달력을 따로 만들 수 있습니다. (추가 설정 없음)
지금은 이 기기에만 저장됩니다. Google Firebase 무료 요금제를 연결하면 가족 모두가 같은 달력을 실시간으로 봅니다. (한 번만 설정, 약 5분)
설정 방법 보기
  1. Firebase 콘솔에 Google 계정으로 로그인 → 프로젝트 만들기 (이름 예: our-family, 애널리틱스는 꺼도 됨)
  2. 왼쪽 메뉴 빌드 → Authentication → 시작하기 → 로그인 방법에서 익명을 사용 설정 후 저장
  3. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3 (서울) → 프로덕션 모드로 시작
  4. Firestore의 규칙 탭에 아래 규칙을 붙여넣고 게시 (가계부와 같은 규칙이라, 가계부용 프로젝트를 그대로 써도 됩니다)
  5. 프로젝트 개요 옆 ⚙️ 프로젝트 설정 → 아래쪽 내 앱에서 웹(</>) 앱 추가 → 나오는 firebaseConfig 부분을 복사해 아래 칸에 붙여넣기
가족은 설정 없이 공유 링크만 열면 됩니다.
