부부 공유 (무료)

공유 가계부에 연결되어 있습니다 · Firebase 프로젝트
아래 링크를 배우자에게 보내면, 링크를 여는 것만으로 같은 가계부가 연결됩니다. 링크를 아는 사람은 누구나 볼 수 있으니 부부끼리만 공유하세요.
이미 만든 공유 가계부가 있나요? 복사한 공유 링크를 붙여넣으세요. (홈 화면 앱, 배우자 폰)
지금은 이 기기에만 저장됩니다. Google Firebase 무료 요금제를 연결하면 부부가 같은 가계부를 실시간으로 봅니다. (한 번만 설정, 약 5분)
설정 방법 보기
  1. Firebase 콘솔에 Google 계정으로 로그인 → 프로젝트 만들기 (이름 예: our-ledger, 애널리틱스는 꺼도 됨)
  2. 왼쪽 메뉴 빌드 → Authentication → 시작하기 → 로그인 방법에서 익명을 사용 설정 후 저장
  3. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 asia-northeast3 (서울) → 프로덕션 모드로 시작
  4. Firestore의 규칙 탭에 아래 규칙을 붙여넣고 게시
  5. 프로젝트 개요 옆 ⚙️ 프로젝트 설정 → 아래쪽 내 앱에서 웹(</>) 앱 추가 → 나오는 firebaseConfig 부분을 복사해 아래 칸에 붙여넣기
배우자는 설정 없이 공유 링크만 열면 됩니다.
